# Native process-token opening

Implementation and validation are in progress. The preceding dynamic-table
group reaches this service in smoke and whoami; neither program has completed.
Sixteen native producer records cover initial, boundary, access and lifetime
controls across ARM64, x64 compatibility, x86 and x86-LAA. The final adapter must
use captured access metadata and guest-owned token handles without forwarding
guest requests to the host. See the assumption and scope registers.
