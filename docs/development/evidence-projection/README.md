# Public compiler-evidence projections

One hundred forty-seven historical Cargo streams contained the same private Assist source
import line inside compiler diagnostics: 89 JSON event streams and 58 plain-text
shipping logs. Their current public copies omit the complete private diagnostic
records or warning blocks. Every other byte, including each compiler artifact
record and process/test result, remains in its original order. Original stream and withheld
record sizes/hashes are retained in `manifest.json`; complete originals remain
in the private task cache and prior Git history. This correction does not rewrite
history or assert that historical Git objects were erased.

Historical source and receipt manifests continue to describe their original
checkpoints. Their byte counts and SHA-256 values are not silently replaced with
distribution values. The projection table binds each original identity to the
exact current public identity. The region and namespace portable checkers use
that declared bridge; their runtime, test-selection, native-oracle, archive and
assumption checks remain unchanged. Original private snapshots still validate
under their recorded identities. Older topic checkers remain historical
checkpoint tools; the command below audits their current public projections.

Run `python3 -B tools/evidence/public_projection.py` from the repository root.
It verifies all current projection bytes, excludes private Assist diagnostic
records, requires retained compiler artifact records, rejects product-source
projection paths and checks unambiguous original/published identity pairs.
No Rust/C/C++ implementation, runtime output, test count, archived binary,
dependency, default or ABI changes in this corrective group.

The projection map is versioned outside the historical proof envelopes. Their
file identities refer to original evidence; the map supplies current byte
identities explicitly. A reported checkpoint identity is therefore distinct
from the direct SHA-256 of its public projection. The adapter returns a recorded
identity only for bytes matching a declared published identity exactly.

Subsequent exports must remove private compiler diagnostic records before they
enter a public evidence package, retain the original private stream identity,
and bind the distributed projection explicitly. File paths and source hashes
may identify the private consumer; private implementation snippets are excluded.
